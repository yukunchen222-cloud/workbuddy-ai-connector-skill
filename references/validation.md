本轮发布包的 8 项单元检查全部通过，13 个 JavaScript 文件通过语法检查，Skill 结构检查通过。发布内容扫描没有发现目标规则匹配的令牌、个人安装路径、认证文件、日志、截图或二进制；该扫描范围有限，不是通用安全保证。

## 安装方最小验收

1. `check` 输出成功，目录非空、密钥加密往返通过，配置未写入。
2. `install` 成功且其他模型、MCP 保留，原生 MCP 信任完成。
3. 新建任务选带来源后缀的 Deepseek，指定仅回复一个临时随机字符串；核对实际回复和模型。
4. 查看上下文卡片，并核对会话用量提示的总量；如果支持多档，来回切换一次。
5. 正常退出、重开国内版，验证自动启动；不要强制结束用户已有任务。

如后续验证文件工具，使用专门临时目录，独立核对生成文件，不以模型自报“完成”代替结果检查。
